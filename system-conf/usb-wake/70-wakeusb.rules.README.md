# Пробуждение по внешней клавиатуре (s2idle)

Внешняя беспроводная клавиатура (приёмник YJX_CHIP) воткнута в хаб монитора,
цепочка: `usb5 (root-хаб) -> 5-1 -> 5-1.1 -> 5-1.1.2 (приёмник)`.

Ядро само включает `power/wakeup` у HID-клавиатур, но у хабов дефолт — `disabled`,
поэтому сигнал resume рвётся на первом же хабе и клавиатура не будит систему.
Правило включает wakeup только на этой цепочке хабов; сами устройства не трогаем.
Встроенная клавиатура работает через ACPI и в правиле не нуждается.

## Установка

```bash
sudo cp 70-wakeusb.rules /etc/udev/rules.d/70-wakeusb.rules
sudo udevadm control --reload-rules && sudo udevadm trigger --subsystem-match=usb --action=add
```

`--action=add` обязателен для применения без перезагрузки: `udevadm trigger`
по умолчанию шлёт событие `change`, а правило матчит только `ACTION=="add"`.
При загрузке системы правило сработает само на реальных add-событиях.
Полная проверка — усыпить систему и разбудить внешней клавиатурой.

## Проверка

```bash
for d in usb5 5-1 5-1.1 5-1.1.2; do echo "$d: $(cat /sys/bus/usb/devices/$d/power/wakeup)"; done
```

Все перечисленные узлы должны быть `enabled`.

⚠️ Имена `usb5`, `5-1`, `5-1.1` зависят от порта/топологии. При изменении
подключения (другой порт, другой хаб) посмотреть новую цепочку:

```bash
readlink -f /sys/bus/usb/devices/5-1.1.2   # или актуальный путь приёмника
```
и поправить KERNEL== в правиле.
